# دليل كأس العالم 2034 الرقمي 
موقع شامل يساعد زوار كأس العالم في السعودية بالتنقل,الحجز,الترفيه و المعلومات العامة ليكون رفيقهم الذكي طوال فترة البطولة .
(ابرز مميزات الموقع) :
1-يتضمن عدًا تنازليا مباشرًا لبدء البطولة العالمية . 
2-تجربة سياحية متكاملة : خريطة تفاعلية ذكية ترشد السياح للوجهات و الفعاليات الترفيهية المحيطة بالملاعب و المدن المستضيفة. 
3-الدليل الرياضي الشامل : تنظيم و عرض تفاعلي لجداول المباريات,تفاصيل الملاعب و المدن المستضيفة.
4-الامان و السلامة :توفير وصول سريع و بسيط لارقام الطوارئ, المستشفيات, و مراكز الشرطة لخدمة ضيوف المملكة.
5-تصميم مرن :واجهة مستخدم متجاوبة (Responsive) طُورت برمجيا لتناسب شاشات الجوال و الحاسب الالي.
6-واجهة ثنائية اللغة لخدمة الزوار من مختلف دول العالم.
(اللغات المستخدمة):
*HTML
*CSS
JavaScript
